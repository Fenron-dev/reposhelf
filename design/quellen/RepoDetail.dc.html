Fero

Ein Beschaffungswerkzeug: Es abonniert Webnovel- und Manga-Quellen und liefert fertige Dateien in einen konfigurierten Zielordner. Fero holt, Fundus bewahrt.

Funktionen

  • Webnovel- und Manga-Abos mit Zeitplan
  • EPUB- und CBZ-Verpackung
  • Dreistufige Zielkette mit Ausweichordner
  • Quellenstatus: erkennt, wenn eine ganze Seite ausfällt

Formatierung ohne lokale Toolchain

gh workflow run fmt-patch.yml --ref main
gh run download <id> -n fmt-patch && git apply fmt.patch

Markdown wird wie auf GitHub dargestellt (GFM), inklusive Tabellen, Aufgabenlisten und Code-Hervorhebung.
