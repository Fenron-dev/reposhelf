So legst du einen GitHub-Token an
  1. Auf GitHub einen neuen fein eingestellten Token anlegen (Ablaufdatum nach Wunsch).
  2. „Repository access“: All repositories – oder nur die Repos, die RepoShelf sichern soll.
  3. „Permissions → Repositories“: Contents, Metadata, Actions und Issues jeweils Read-only. Für Builds über GitHub Actions zusätzlich Actions: Read and write.
  4. Token kopieren und oben einfügen.
